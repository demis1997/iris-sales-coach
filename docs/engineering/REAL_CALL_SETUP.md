# Real-call setup — unverified until approved smoke test

No test accounts or approved telephone numbers are currently configured. All paid flags default false. The code has not placed a real call. Do not demonstrate a control as operational before completing this guide on a non-production setup.

## Required setup

1. Dedicated Supabase project with all migrations applied and two distinct test organizations. Configure Auth site/redirect URLs. Verify upload, membership revocation, cross-tenant access, private Storage and Realtime with actual user tokens.
2. Dedicated Twilio account/number with an approved test destination, verified agent handset, geographic permissions, jurisdiction/marketing consent review and account-level spend controls. Store server credentials securely. `APP_URL` must be the actual reachable HTTPS origin used in Twilio signature calculation.
3. Set a company caller ID through `/ceo/telephony`, enable company calling, verify the agent's handset through `/app/settings`. `ARTEMIS_ENABLE_REAL_CALLS=true` permits paid SMS and call actions. Calling is role-limited and requires an operator-attested marketing-consent record reference; this is not independent legal proof of consent. Suppression checks fail closed.
4. Keep recording disabled. The live call action refuses recording-enabled settings because a reviewed recording-consent workflow is not complete. Historical recording ingestion is hardened, but recording permission/retention must be implemented and tested before enabling new recordings.
5. Run the Node voice worker on persistent infrastructure with TLS WebSocket proxying. Set `MEDIA_STREAM_PUBLIC_URL=wss://your-voice-host/media`; allow Twilio to reach it. Upgrade signatures use the fixed configured public HTTPS equivalent, not a forwarded Host header. Set Deepgram and Venice credentials/model plus explicit paid-AI/voice flags before starting `npm run worker:voice`.
6. For inbound AI, create an admin-controlled `voice_workflows` row with enabled=true and configuration matching `src/lib/voice/workflow.ts`: version, en/ru language, purpose, accurate product knowledge, AI disclosure, discovery questions and approved human-handoff number. Configure Twilio incoming voice webhook `POST https://your-app/api/twilio/inbound`. Select an actually supported TTS voice/model. For Russian TTS use a verified multilingual ElevenLabs setup if the chosen Deepgram voice does not support Russian.
7. Outbound agent click-to-call uses signed `/api/twilio/voice`, `/status` and optional historical `/recording` callbacks. The voice handler starts both-track streaming when enabled, then bridges the prospect. The dashboard's current call state/metrics describe the parent agent leg; prospect-leg status is not fully tracked.
8. Start `npm run worker:reconcile` to refresh non-terminal calls with known provider SIDs (including inbound calls and missed callbacks). It reads provider state, never creates calls. Unknown outcomes without a SID require manual provider reconciliation. Start `npm run worker:analysis` after approval for provider usage. It reads actual speech or explicitly operator-provided transcripts and commits the summary atomically. CRM outbox remains blocked until a real adapter is implemented.

## Explicitly approved real-provider smoke test

Before testing, obtain approval for the test number, call purpose, participating test users, maximum duration and monetary spending ceiling. Enforce the ceiling at the provider/account level; application duration bounds alone cannot guarantee a currency cap. No automated test invokes this procedure.

Create one test lead in `/crm/contacts`, record its consent reference, and select that consented lead in the dialer; initiate one call through the dialer. Reusing the same request key must not dial twice. Answer the handset/test destination. Observe actual transcript/coaching events; speak over an AI response in an inbound test, request a human and opt out. End the call, inspect provider state, transcript provenance, summary, call events and real metrics. Verify an opt-out adds suppression before any subsequent outbound attempt. Verify second-organization users cannot retrieve the call or subscribe to its live events. Record real stage timings and telephone playout/round-trip measurements. Inspect actual invoices separately from configured estimates.
